A real world distributed backend system in Go using modern microservices architecture.

 distributed system with:

    Broker Service (API Gateway style entry point)
    Authentication Microservice (PostgreSQL)
    Logger Microservice (MongoDB)
    Mailer Microservice
    RabbitMQ Event System
    RPC Communication Layer
    gRPC Communication Layer
    Docker & Docker Compose Infrastructure

Technologies Used

    Go (Golang)
    Docker & Docker Compose
    PostgreSQL
    MongoDB
    RabbitMQ
    REST APIs
    RPC
    gRPC
    Microservices Architecture
